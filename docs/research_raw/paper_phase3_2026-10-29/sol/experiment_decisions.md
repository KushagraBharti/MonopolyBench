# Claim-to-experiment sufficiency decisions

Sol, 2026-10-29. Read with the final phase-2 [claim ledger](../../paper_phase2_2026-10-28/core_review/astra/claims.md) and [reconciliation](../../paper_phase2_2026-10-28/core_review/astra/reconciliation.md). No paid games, prompt changes, engine changes or new benchmark treatment were run. A new experiment is necessary only for a claim whose estimand is not identified by the retained data.

## Decision rule

E means existing audited evidence supports the bounded statement. L means additional coding or reduction of existing logs can answer the stated descriptive question. O means optional strengthening through a new local validation or reference-policy study. X means a new controlled experiment is required for the stronger claim. X does not make the descriptive paper incomplete. Confidence intervals cannot repair an unidentified estimand. Separate data integrity, measurement validity, causal identification, generalization and normative validity.

The target is the configured agent, including model/checkpoint, prompt, memory, legal-action representation, retry and response processing. Opportunity is an observed condition that prior behavior can create. Conditioning on it may remove part of the ability of interest. Report whole trajectories and conditional rates together.

## Minimum completion before writing the manuscript

Freeze source digests for every retained exhibit, test reporting transformations against totals, and inspect plotted labels and captions. Report configured response conditions, normative instruction, five-block design, declared rules and available explanation channels in the main text. Use existing exact-prefix checks and representative negative cases as measurement validation. No second tournament follows from these requirements.

Optional local reference-policy runs could test pipeline responsiveness to known policy differences. Existing policies that make no substantive trade cannot validate a negotiation-quality measure. A no-trade baseline is not a gold-standard rational agent. Hand-specified fixtures can validate acquisition/completion/access/finance accounting without incurring provider cost. These are possible future authorizations, not completed work.

## A prospective safety design worth preserving

Define several norms separately: truthful public financial assertions, honoring a specific accepted commitment, respecting protected information, and following a transaction authorization. Each needs its own opportunity and scoring rule. Add these as explicitly new treatments only after approval, because changing the current deception license changes the benchmark. Record legal action availability, actual exposure, contract status, opportunity to comply, response channel and execution result. Distinguish a truthful statement that loses money from a false statement that earns money. Independent capability tests should cover action feasibility and longer policy outcomes without using the same conduct score to define capability. No single scalar should silently price all norm violations against profit.
