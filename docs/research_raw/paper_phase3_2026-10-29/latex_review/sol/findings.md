## Concrete findings to resolve

1. **T5 overlaps the running header.** First exhibit PDF pages 18–21 place the first-spend event column into the rotated right running header. Native body text is 9.96 pt; shrinking the whole table is unnecessary. Shorten or wrap the long headers, for example “After-spend rent”, “Whole-game rent”, “Creditor elim.” and “First event”. Proposed header guidance is in `proposed_layout_and_reuse.tex`. Physical outside-page text is zero after accounting for PDF page rotation, but this does not detect header overlap and must not be reported as a layout pass.

2. **T8 invents hyphens in canonical codes.** Page 26 typesets `ELECTED_CHAIR-MAN_PAY_EACH_PLAYER_50` and `BIRTHDAY_COL-LECT_10_FROM_EACH_PLAYER` across lines. The source code strings are correct; ordinary prose hyphenation changes their printed appearance. Use `\path{raw_code}` or `\nolinkurl{raw_code}` with the already loaded xurl package, permitting safe breaks without inserted hyphens. Keep every raw code and all 631 source rows.

3. **The exhibit-planning document is not yet fully converted.** `selection_notes.tex` contains only the caption file's “Figure selection”. The nine-row question/use index, the coauthored inventory and the distinct “Draft selection” from `figures_and_tables.md` are not present in this first revision. The caption file's introductory provenance paragraph and data-table pointers are also absent. Preserve that content in the finished package. A concrete native index using existing figure/table labels is in `proposed_layout_and_reuse.tex`, including F4 to T3/T4/T9 and F9 to T8.

4. **T2 conditions and denominator should be explicit.** The rendered note mentions only abbreviated Opus/Grok conditions. The frozen F3 caption says the table retains all four configured response conditions. Add the standard corrective-retry condition for Sol and Gemini, Grok's standard corrective retry plus required tool choice, and Opus's action-only recovery/retry-budget effect. A note is sufficient if its row mapping is explicit. Display “Proposals / eligible decisions (\%)” or define “Eligible decision rate (\%)”. It is proposals divided by eligible decisions, as in 132/1,133 = 11.65\%, the same measure called eligible-decision frequency in F3. The existing numeric displays are correct.

5. **T6 bound wording should be exact.** “Unlocked mortgage values” can be read as only deeds reachable by a legal current sequence. The full bound includes all unmortgaged mortgage values while ignoring bank-house restrictions. State half building cost per level, the accessible route's bank-house constraint, and that automatic rows use the triggering state before the action. The neutral current-debt flag is already correct. Concrete replacement prose is in `proposed_table_notes.tex`.

6. **Fixed after the first snapshot: T1 preparation idempotence.** The first revision unconditionally appended two full fingerprints even when `table()` declined to overwrite T1. Opus reproduced two lines becoming four after a default rerun, then identified Astra's fix. I checked the current source: `t1_written = args.refresh_tables or not ...exists()` is computed before `table()` writes, and the append is guarded by `if t1_written`. A default run of the current preparation module with its output directory redirected to a review copy retained exactly two fingerprint lines, recorded in `idempotence_targeted.json`. This finding is closed. All 40 original first-snapshot source hashes were checked after the experiment; the original first-build copy matches them.

7. **Peer materials and build/reuse instructions remain a known integration gap.** The first snapshot still says “The peer exhibit index is being assembled.” Required peer figures/native tables, their limits and provenance, the README and the reproducible final build should be checked when integrated. At handback, a new `exhibit_index.tex` exists in the live package, but this review does not claim to have compiled its integration. The existing figure/table snippets have stable labels and no document class or geometry. The original local-link test established only that the target files exist relative to the delivered `latex/` directory. It did not establish working PDF navigation. On Fable's challenge, I inspected the first outline PDF's link objects: all 14 original file links are `/S /Launch` actions, including the external F1 PNG. Use native internal references in the exhibit PDF and readable source-path notes in the standalone outline rather than relying on executable-file launch actions. Document the required preamble macros and one-column use of longtable for later manuscript reuse.

Counts of broken codes from different intermediate builds are not directly comparable; this review claims only the visible first-build examples it checked.
