# MonopolyBench LaTeX drafting package

The paper outline, figure captions, exhibit-selection plan and data tables are now editable LaTeX. This is the steps 11–14 drafting package, not the full manuscript. The literature review and all four bibliographies remain unchanged in the parent archive.

## Open or build

- `paper_outline.tex` → `paper_outline.pdf`
- `figures_and_tables.tex` → `figures_and_tables.pdf`
- `outline_body.tex` contains the editable section plan.
- `figures/` contains reusable figure snippets and complete captions.
- `tables/` contains native LaTeX tables, including all 837 primary records and detailed provenance companions.
- `assets/` contains the original vector PDFs and clearly labelled raster peer exhibits.
- `data/` contains the unchanged primary CSV/JSON pairs and supplementary data.

With LuaLaTeX and latexmk installed (tested with TeX Live 2026):

```sh
bash build.sh
```

Run this command from the package directory, or pass the absolute path to `build.sh`. TeX Gyre Pagella, TeX Gyre Heros and Latin Modern Mono are included in standard TeX Live installations. No shell escape, browser, network or Python is needed for a normal build. Compiler intermediates go to `build/`; the two final PDFs are copied to this directory. A fixed source date is set; byte equality across different TeX/font versions is not promised.

For Overleaf, upload the source ZIP, select LuaLaTeX, and select either main `.tex` file. No venue template has been imposed.

## Reuse and provenance

F1–F9 and T1–T9 keep the source identifiers. T6a and T9a expose ordered liquidation routes and complete decision provenance for the same records. S-prefixed figures/tables and OC-prefixed author proposals are separate supplementary exhibits. They are alternatives and supporting material, not additional independent datasets or a requirement to print the entire exhibit book in the paper.

Internal exhibit references navigate within the PDF. Outline references print archive paths in footnotes; there are no PDF Launch actions. Full source hashes are in `source_manifest.json`, `supplement_manifest.json` and `verification.json`. Copied Markdown files are provenance snapshots; edit the LaTeX for subsequent manuscript work.

Only the primary nine tables are regenerated by `tools/prepare_sources.py --refresh-tables`. Prose and captions are imported once and then protected from that command. Within the original repository, `prepare_supplement.py` and `complete_conversion.py` integrate the retained peer proposals and disclosed conversion fixes. Those maintenance scripts require the original phase-3 archive and `markdown-it-py`; they are not needed to build the supplied sources. Do not regenerate after editing a generated table without preserving the intended changes.

The team’s source and rendered reviews are archived outside this ZIP under `../latex_review/`. `conversion_log.md` records which findings were fixed and the two scientific wording qualifications that are explicitly footnoted.
