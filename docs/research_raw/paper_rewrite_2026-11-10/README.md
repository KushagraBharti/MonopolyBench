# MonopolyBench paper rewrite

Start with [the integrated paper](integrated/manuscript.pdf) and its [LaTeX source](integrated/manuscript.tex). Build instructions are in [integrated/README.md](integrated/README.md).

The paper follows bargaining, development, financing and creditor inheritance across twenty complete games. Eight contextual transcript incidents accompany the results, and the discussion maps all eight motivating questions plus A–C to the evidence available.

Astra, Sol, Opus and Fable 5.2 each produced a complete independent paper before cross-reviewing all four. `full_drafts/` preserves those manuscripts, `reviews/` the cross-reviews, and `final_review/` the integrated-paper reviews and root dispositions. `integrated/` contains the final synthesis, figures, source data, verification reports and provenance.

This revision uses only the existing corpus and retained analyses. No new games, model evaluations or engine continuations were run. The original outline, prior papers, literature review, canonical games and benchmark implementation are unchanged.

Additional referee feedback supplied on 11 November is preserved in [the feedback archive](feedback/2026-11-11_additional_referee/user_review.md). The [assessment](feedback/2026-11-11_additional_referee/assessment.md) separates accepted issues, qualified claims and proposals outside the authorized scope. This feedback pass leaves the integrated manuscript unchanged.
