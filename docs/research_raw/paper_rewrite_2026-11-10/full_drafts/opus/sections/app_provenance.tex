\paragraph{Research-assistance runs.} Earlier extraction, review and drafting used four LLM research-assistance runs: GPT-6 Astra, GPT-6.1 Sol, Claude Opus 5.5 and Claude Fable 5.1. The Sol and Opus runs share model families with evaluated participants, and review was not blinded to this. The later agenda extension and its checks used Astra instances. This draft was written by a Claude Opus 5.5 run working independently of the parallel drafts. Agreement among these runs is not human annotation and is not evidence of label validity.

\paragraph{Quotations.} Shared quotations come from the baseline manifest, which records each span's source file, JSON pointer, line, code-point offsets and hashes. Quotations added here are generated by \path{tools/build_opus_quotes.py}, which reads the canonical files, checks that each excerpt is a contiguous substring of the applied field, and writes the macros and \path{data/opus_quote_manifest.json}. Bracketed ellipses mark omitted text, and quoted text is not corrected.

\paragraph{Literature.} Version numbers and venues of works added in this draft were checked on arXiv abstract pages, the ACL Anthology, or proceedings listings on 10 November 2026, as recorded in each bibliography note. For several recent preprints we read only the abstract page, and for CICERO and the AI-deception survey we relied on bibliographic records found by search; we cite these works only for claims their abstracts state.

\paragraph{Build.} From this folder, run \path{python3 tools/retabulate.py}, \path{python3 tools/build_tables.py} and \path{python3 tools/build_opus_quotes.py}, then \path{latexmk -lualatex manuscript.tex}. The figures and shared quotation macros are read from the shared \path{../../assets/} and \path{../../sections/} folders.
