\section{Legal-sequence certificates}
\label{app:certificates}

The certificate package (\path{artifacts/historical-claim-audit.zip} in the baseline draft folder) contains all twenty original action streams, engine settings, a reference digest for every canonical event, 126 case records, an unchanged copy of the engine and board, pinned dependencies, a runner and nine tests. It replays all 50,918 events and re-executes all 126 cases without a repository checkout. A clean extraction in a fresh environment reproduced the retained results, and a separate reviewer re-executed the package and checked the original selection of cases. These checks predate this draft; we did not re-run them (Appendix~\ref{app:provenance}). Population completeness and the transcription of attempts were checked against the full canonical records, which the small package does not contain.

\paragraph{The bundled-sale counterexample.} An initial checker tried to certify impossibility by exhausting atomic sales and mortgages. A reviewer constructed a counterexample with no bank houses in which the engine accepts a bundled dark-blue hotel-and-house sale that no atomic sequence reaches; the preserved synthetic test pays \$750 Illinois rent with \$250 left. The revised checker refuses a search-based impossibility certificate whenever any visited state offers a building sale, and reports such a case as unresolved. The one historical search certificate, G7 d339, offers only a mortgage and a declaration, so it is unaffected.

\paragraph{Construction targets.} The 66 default decisions contain 132 attempts: 70 well-formed targets, one malformed target and 61 attempts without a parseable target. All 70 encodings are invalid as written. Atomic expansion preserves each deed and building-type count; 63 targets execute and seven cost more than current cash. The constructive ordering is not a general solver. No residual case arose in which an affordable target failed to execute.
