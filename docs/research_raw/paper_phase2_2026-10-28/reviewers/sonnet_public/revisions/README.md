# Revision log (versions)

Initial labels (v1) were written independently while reading. Later corrections (v2) come from the lead's public-source checks (messages 1 and 2 on 2026-10-28) or are self-initiated wording changes in the same spirit; each is logged in `gXX_change_log.jsonl` with `initial_value`, `revised_value`, `reason`, and `revision_source`, so initial and corrected labels stay distinguishable. Candidates in `candidates.jsonl` carry `revision_history` (change ids) and `current_version`.

The lead's audit files (`astra/g01_candidate_audit.*`) were deliberately **not** opened by this reviewer, to keep the independent pass independent; corrections were applied from the lead's written messages only.
