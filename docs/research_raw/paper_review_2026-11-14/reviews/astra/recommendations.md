# Recommendations after the full feedback review

These are recommendations, not authorization to execute experiments. The no-new-evaluations instruction remains in force, including free engine runs, baselines, replay probes and synthetic scenarios.

## Decision to make before another manuscript

Freeze the scientific question rather than choosing a new title from the latest review. The current question can be: **what do the recorded financial assessments contain, and where do those assessments agree or disagree with applied actions and outcomes?** That is answerable descriptively from this corpus. A future causal question — whether current-action-centered interfaces increase false infeasibility and premature stopping — requires a new study.

Do not promise that a new controlled result must be a memory effect, a planning failure, or an interface defect. The procedure should distinguish those possibilities and permit a result that makes the original explanation less interesting.

## Work compatible with the existing-data scope

1. **Complete the evidence table before editing the abstract.** Use all 188 episode entries, preserve every available response field and record the applied action. Fix a codebook before semantic expansion. Score feasibility statements, inventory completeness, dependency recognition and arithmetic separately. Preserve uncertainty and missing statements. A machine-extracted field is not a human judgment.
2. **Put the sixteen in context.** Retain their complete enumeration. Add the six above-bound financing starts and the Grok payable declaration. Explain why the same outcome can reflect an assessment omission, a wrong transition belief or call/text disagreement.
3. **Correct the task labels.** Use “requires released collateral” where the one-way bound plus feasibility warrants it. Avoid asserting that an upper-bound-sufficient middle tier has an alternative executable route unless demonstrated. Describe dependency depth and menu assistance separately from action count.
4. **Document the memory hypothesis accurately.** The carried $130 and $30 are conditional inventories, not demonstrated corrupt memories. Include successful expansions of carried inventories. A statement that a figure reappears is supportable; a causal memory explanation is not.
5. **Make the text selection auditable.** Print both private and provider fields for sixteen focal cases, or provide one linked side-by-side table. Mark joint note/action generation and provider summaries. Do not flatten inconsistent channels into a single inferred belief.
6. **Keep bargaining at its supported level.** Full counts, offer-form and proposer composition, selected rival-focused language and economic trajectories remain useful. No general completion premium, causal persuasion, absence-of-effect claim or intrinsic model ranking.
7. **Repair release completeness.** Package the actual build script, ledgers, manifests and source map; make the repository paragraph point at a real immutable release. The current package is untracked. This review makes no commit or push.
8. **Choose a publication form and accountable byline.** A named preprint and an anonymous submission require different metadata. Humans must own the claims and annotation decisions. The author list should not be inferred by the assistants.

This work can produce a better observational paper. It cannot establish an intervention effect, learning, generalization or a validated general auditing method. The broad eight-question map can remain in supplementary material; the main text should answer a few questions well.

## Work requiring a change to the no-new-evaluations instruction

### Gate 1: establish the measurement target and reference policies

Before new LLM calls, define a strict diagnostic objective: pay the obligation if legally reachable, otherwise report infeasibility or declare according to the contract. This differs from the historical “cannot or should not” instruction.

Keep three reference objects separate:

| Reference | Question answered | Required record |
|---|---|---|
| Feasibility verifier | Does any legal payment route exist? | Positive witness, sound negative bound or complete search; unknown on timeout |
| Transparent reactive policy | How much does refreshed-menu execution accomplish without advance assessment? | Exact ordering, legal interface, all actions and termination |
| Cost-minimizing policy | What is the minimum of a specified local liquidation cost? | Objective definition, solver completeness/gap, executable minimizing plan |

The theorem or search must use the actual proposal restrictions, including hotel stock and bundled-sale semantics. An internal engine transition accepted by a validator is not automatically an action the interface exposes. Verification against the same engine establishes consistency with that implementation; intended-rule correctness is a separate check.

Define restoration cost before computing it. Specify whether costs are sunk destruction, future restoration expenditure or lost strategic value. Track borrowed principal and recovered cash consistently; include engine-specific interest rounding only for the historical rule regime. Report payment success, unnecessary persistence, invalid calls, calls/cost and local preservation separately. A defaulting agent cannot quietly disappear from a conditional-regret average.

### Gate 2: independent assessment and execution

Use the same state but independent instances for a structured assessment and an execution run. The assessment can report payable/infeasible/uncertain, usable resources and expected budget. The execution instance should not receive that assessment. A forecast-then-act condition is a separate intervention because it may improve performance.

Keep matched states across configurations, consistent identities and observation contents. Resolve provider refusals and tool-choice behavior before collection and freeze the policy. A comparison between different recovery regimes is a comparison between configured systems, not just model weights.

### Gate 3: one discriminating manipulation

| Candidate contrast | What it can identify | Main confound to prevent |
|---|---|---|
| Same explicit facts, different organization | Representation effect under that task | Adding deductions or changing callable options |
| Primitive values supplied versus absent | Effect of numerical information | Simultaneously changing rules or history |
| Rule supplied versus absent | Effect of rule information/salience | Calling the effect proof of recall versus reasoning |
| Current legality plus informational capability catalog | Value of future-capability visibility | Changed schemas, invalid-action possibilities or feedback |
| Notes removed versus retained | Total effect of this memory package | Claiming a specific number effect when other facts and length change |
| Factual inventory perturbation | Sensitivity to a false or stale resource estimate | Inconsistent state history and content-dependent implausibility |
| Reserve instruction perturbation | Sensitivity to a preference or constraint | Treating compliance as an unambiguous reasoning error |
| Generic reconsideration versus targeted correction | Incremental benefit of the target content | Extra calls, tokens or retry opportunity |

The strongest candidate from the current corpus is a conditional inventory becoming stale when building sales change eligibility. It is a hypothesis, not yet the thesis. A broad catalog that allows illegal calls is an interface-policy experiment; reordering an identical catalog is a representation experiment. They should not share one causal label.

### Gate 4: fresh state families and negative controls

Include ordinary payable, dependency-payable, upper-bound-impossible and nominally-rich-but-unreachable states. A correction that merely encourages continuation can harm impossible states. Match or record cash margin, portfolio size, values, action count, dependency structure and binding stock constraints.

Natural snapshots, legal generated states and altered obligations should be labeled separately. Debt variants of one portfolio remain one related family. Update or remove incompatible history when editing a state. Counterfactual rules require an equally changed transition model and valid labels, not just a sentence in the prompt.

Repeating the sixteen discovery states is an implementation and variability check. It is not independent confirmation. After a pilot, freeze the state construction, primary contrast, exclusions, outcomes, analysis and stopping rule in a dated commit. Confirm on fresh families. Do not select a larger experiment only because one pilot subgroup looks favorable.

### Gate 5: analysis and stopping criteria

Use paired state-level contrasts and configurations reported separately. Repeats are nested in state families; related natural states are also nested in source games. Interleave collection conditions to reduce wall-clock drift. Few-family mixed-effects fits need caution and diagnostic reporting. Report uncertainty at the level the sampling design supports.

Stop calling the task difficult planning if reactive policies and systems are at ceiling. If supplied values remove errors, report information sufficiency. If assessment is correct and actions fail, study execution. If only historical examples show the effect, retain a narrow case study. If an intervention decreases false surrender but increases wasted activity, report that tradeoff.

Any cost estimate must count full execution calls, retries, context and provider changes. No $40 or $150 promise is supported by the historical average alone.

## What I would not prioritize

- Another unstructured 100-game corpus before defining a measurement.
- All memory, rule, value, name and tool-choice manipulations at once.
- A solver intervention in live games as a substitute for a clean state-level comparison.
- More model-family judges as a substitute for a human reference when the claim relies on semantic validity.
- Renaming the board as the sole proof of general reasoning.
- An arbitrary reference count, a universal nine-page target, or an acceptance forecast.
- Turning the current paper into an unvalidated auditing-method paper.

## Publication judgment

The current evidence can support an openly scoped observational contribution and a useful release. A stronger main-track claim needs an identified empirical relationship, a calibrated diagnostic with meaningful coverage, or another contribution of comparable weight. The exact venue and track matter; neither rejection scores nor promises of acceptance are facts established by this review.
