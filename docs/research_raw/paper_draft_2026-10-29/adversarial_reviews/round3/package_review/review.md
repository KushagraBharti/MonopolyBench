## Required corrections

LaTeX treats the first pair as a line break and typesets the remaining reference text. Replace those commands with ordinary single-backslash references. The current verifier reports no unresolved references because its expression can match the second slash; it does not establish that the rendered text contains usable references. Evidence: [page 3 crop](rendered/broken_ref_p03.png), [page 30 crop](rendered/broken_refs_p30.png).

2. **Preserve spaces in the executable commands.** Page 31 renders `pythonrun_audit.py --outputreproduced.json` and `pythontest_certificates.py`. These are also the strings extracted from the PDF. `sections/audit_appendix.tex:6` puts shell commands through `\artifact`, defined as `\path`, which removes their spaces. Use a code/verbatim treatment that preserves spaces, then check the rendered and copied text. The README inside the certificate ZIP has correct commands, so the audit itself remains runnable. Evidence: [command crop](rendered/commands_p31.png).

3. **Move Figure 4's zero-receipt notes away from data.** On page 33 both notes intersect high-rent markers. In the winner panel, the “24 zero-receipt units” annotation crosses several circles near the top left. The notes describe baseline units while visually covering other observations. `tools/build_exhibits.py:99` fixes the note at axes coordinates `(0.03, 0.96)`, where data exist in both panels. Put each note in a subtitle, margin or caption. Evidence: [Figure 4 crop](rendered/figure4_overlap_p33.png).

4. **Extend portable verification to the new evidence files.** `tools/verify_draft.py` checks older aggregate exports but never reads `resolution_conditions.json`, `certificate_results.json`, `first_management_windows.json` or `opportunity_ledger.json`. An isolated mutation probe set the Sol END count, reachable-default summary and first opportunity cell to `999999`; `--portable` still returned `pass`. This does not invalidate the unchanged data: my independent checks reproduce them. It does mean the current command cannot detect corruption or staleness in the new central results. Add record-level END partitions, certificate-summary consistency, complete 80-cell reaggregation, source digests and displayed table checks. Evidence: `verifier_mutation_probe.json`, `independent_checks.json` and the preserved `mutated_verifier_probe/` copy.
