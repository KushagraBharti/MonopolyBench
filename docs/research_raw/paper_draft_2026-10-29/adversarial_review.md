## Design constraint for the added analysis

Do not create a weak menu heuristic merely to show that the executable method wins. The comparison should report what each evidence level establishes, using explicitly defined predicates. A nominal upper bound is allowed to leave a case unresolved. It is not an incorrect classifier unless someone incorrectly treats it as reachable wealth. The scientific result is a verified distinction among evidence and outcomes, not an invented annotation-accuracy improvement.
