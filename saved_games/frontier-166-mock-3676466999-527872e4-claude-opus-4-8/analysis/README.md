# Analysis

This directory contains deterministic quantitative artifacts and an exhaustive manual qualitative layer for `mock-3676466999-527872e4`.

## Qualitative review

- `review/chronological_turn_review.md` — every turn and decision in contiguous ≤3-turn blocks.
- `review/player_dossiers.md` — four evidence dossiers without rankings.
- `review/bankruptcy_windows.md` — each terminal decision with ±5-decision window and legal menu.
- `review/negotiation_review.md` — every proposal/counter/accept/reject episode.
- `review/evidence_index.csv` — every event plus every applied decision.
- `review/review_packet.jsonl` — 488 joined decision packets.
- `review/promise_lifecycle.csv` — high-precision future-commitment candidates.
- `review/communication_claims.csv` — economic/mechanism claims with bounded adjudication.
- `reports/case_studies.md` — mechanism-diverse, deeply sourced cases.
- `reports/manual_review_report.md` — scope, findings, limitations, and reliability.

Canonical `run/` and `quality_check/` evidence is immutable. Qualitative files distinguish fact, reported reasoning, interpretation, uncertainty, and speculation. No provider/model calls were made.
