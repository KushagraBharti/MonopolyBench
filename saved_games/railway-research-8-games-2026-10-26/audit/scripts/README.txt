verify_collection.py is the repeatable read-only verifier, adapted from b480e987. It needs the installed MonopolyBench Python packages and requires an earlier collection with an audit/download-index.json. Other scripts record the download/audit/assembly procedure; do not rerun the importer blindly. Auth is loaded from the existing local Railway CLI login and stays in memory. The one-time auth helper expects a CLI at /tmp/mb-railway-cli/node_modules/.bin/railway. No credential values are embedded in these scripts.
